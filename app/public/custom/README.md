# Custom portraits (private)

Drop your own images here to replace the drawn faces in your own build.
Nothing in this folder is committed except this file.

| File name | Replaces |
| --- | --- |
| `avatar-0` … `avatar-11` | The 12 lobby faces (0 = Akira, 1 = Yuki, … 11 = Luna, in the picker's order) |
| `char-killer` | The Killer's exclusive character (Shuten): reveal card, finisher, game over |
| `char-judge` | The Judge's exclusive character (Rei Tenbin): hearing intro, game over |

- Formats: `.png`, `.jpg` or `.webp` (for example `char-killer.png`).
- Square images work best. Keep the face centred in the upper half: the
  panels crop to the eyes at about 36% from the top.
- Custom images don't animate (no blinks, winks or raised brows); eye
  contact still shows through the panel's glow and labels.
- After adding files, refresh the browser, or rebuild the app for phones.
